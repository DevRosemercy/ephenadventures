Ephen Adventures and Social Club

Explore. Connect. Experience.

A modern, responsive web application for Nairobi’s premier social travel and adventure club.

📖 Overview

Ephen Adventures and Social Club is an all-in-one web platform designed to showcase outdoor adventure packages, facilitate seamless trip bookings via WhatsApp, and foster a vibrant travel community in Kenya. From single-day mountain hikes to multi-day coastal escapes and safaris, this application offers an intuitive interface for travelers to discover, plan, and book their next experience.

✨ Features

🎨 Modern & Adaptive UI: Built with Tailwind CSS, supporting seamless Light and Dark mode transitions.

📱 Mobile-First Responsive Design: Optimized for mobile users with a sticky bottom booking bar and responsive navigation drawer.

🏞️ Interactive Destinations & Trip Cards: Filterable adventure catalog (Hiking, Safaris, Camping, Beach Getaways) with video preview modal popups.

💬 Direct WhatsApp Integration: Instant booking forms that construct pre-formatted WhatsApp messages directed to the adventure coordinator.

👥 Private & Corporate Group Requests: Dedicated modal for requesting custom itineraries, team building, and special group celebrations.

🤖 Embedded AI Safari Assistant: Interactive virtual guide to help users with gear recommendations, pricing, and FAQ inquiries.

🔐 Admin Control Portal: Protected portal allowing quick adjustments to live website metrics (Trips completed, active members, community ratings).

🛠️ Tech Stack

Markup & Content: HTML5

Styling: Tailwind CSS (CDN)

Typography: Google Fonts (Plus Jakarta Sans & Playfair Display)

Scripting & Logic: Vanilla JavaScript (ES6+)

Storage: Browser localStorage for dynamic admin metric persistence

🚀 Quick Start / Local Setup

Because this project is built as a single, self-contained application, running it locally requires no build steps or heavy dependency installations!

1. Clone the Repository

git clone https://github.com/YOUR_USERNAME/ephen-adventures.git
cd ephen-adventures


2. Open in Browser

Simply double-click the index.html file (or gemini-code-1792755794701.html) in your file explorer.

Alternatively, use VS Code's Live Server extension to launch a local development server.
